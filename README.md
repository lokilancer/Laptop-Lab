## Featured Project

### Laptop Lab
An expedition-styled browser app that tests your laptop hardware. Nothing to install—everything runs in your browser with comprehensive checks for display, camera, microphone, keyboard, speakers, battery, network speed, Wi‑Fi stability, performance benchmarks, and system information.

A guided run walks you through every check in order. Checks that find a problem — such as a slow connection, unstable Wi‑Fi, or low battery — get flagged, and the report summarizes what needs attention.

- **Built with**: HTML, CSS, JavaScript
- **Features**:
  - Display testing
  - Camera and microphone testing
  - Keyboard and touchpad checks
  - Speaker and battery diagnostics
  - Network speed and Wi‑Fi stability testing
  - Performance benchmarks
  - System info dashboard
- **Highlights**: Full hardware diagnostics, guided test runs, offline support, installable as a PWA
- **Link**: [GitHub](https://github.com/lokilancer/Laptop-Lab)
